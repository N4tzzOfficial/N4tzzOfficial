## `> featured_project`

### ⚡ NzRouter

One of my projects that I'm actually proud of.

**NzRouter** is an upgraded router project inspired by the concept of **9Router**, rebuilt with my own direction and architecture.

It's available through **NPM** and is part of the developer-tool ecosystem I'm building.

```bash
npm install nzrouter
```

```text
NzRouter
   │
   ├── routing
   ├── middleware
   ├── developer utilities
   ├── extensibility
   └── future ecosystem
```

**status:** `published / evolving`

> I don't want NzRouter to stay as "just another package".
> There's more planned for it.
